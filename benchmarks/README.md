# Stem experiment archive

Historical results, decisions, comparison conditions and commands stay in the active tree. Raw signed workloads, event traces, logs and large proof packs are linked at the pinned [pre-cleanup Git revision](https://github.com/a19q3/stem/tree/12338f2fea73c8df437694da473d08e950a0938b). The [archive inventory](archived-inputs.tsv) records the original path, Git blob ID and byte count of each relocated file. Compact regression corpora for ordinary Spore and the follower pipeline stay beside their verifiers. This preserves both accepted and rejected experiments in the results record.

For a small checkout of the current main branch, use a shallow clone.

```sh
git clone --depth 1 --single-branch --branch main https://github.com/a19q3/stem.git
```

To fetch a single input for an existing replay command, download the artifact linked in the report. The manifest lets you verify a download by running `git hash-object <file>` and comparing the listed object ID. A clone that already has the archived commit can export just the required file.

```sh
git show '12338f2fea73c8df437694da473d08e950a0938b:<archive-path>' > /path/to/replay-input
```

Older commands that expect several archives at their original paths can run from a separate worktree of the pinned revision. A full clone or checkout of that revision includes the original bulk data.
